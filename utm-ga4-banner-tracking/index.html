UTM Tracking for Banner Ads

แนวทางวัดผลโฆษณาใน GA4 ให้ข้อมูลสะอาด เทียบกันได้ และต่อยอด optimize ได้จริง

สำหรับทีม Marketing, Product, Analytics และ Engineering

ทำไมเราต้องคุยเรื่องนี้ตอนนี้

ตอนนี้เรามี GA4 ติดตั้งแล้ว, เปิด Enhanced Measurement แล้ว, และเห็นข้อมูลใน Realtime แล้ว - แต่ถ้ายังไม่มี UTM standard กลางของทีม เราจะเทียบ performance ของ banner แต่ละตัวได้ไม่ดีพอ

พร้อมแล้ว GA4 foundation
ยังขาด UTM naming convention
เป้าหมาย traffic + conversion visibility

ถ้าไม่มีมาตรฐาน

  • source สะกดหลายแบบ
  • campaign เทียบกันยาก
  • creative ไหนดีไม่ชัด

ถ้ามีมาตรฐาน

  • ดู performance รายเว็บได้
  • เทียบ placement / size / variant ได้
  • โยงไป conversion ได้จริง

กรอบความคิดที่ทีมต้องตรงกัน

UTM

บอกว่า session มาจากไหน

source / medium / campaign / content

Events

บอกว่าผู้ใช้ทำอะไรบนเว็บ

click, form_start, form_submit

Key events

บอกว่าอะไรคือผลลัพธ์ที่ธุรกิจแคร์

generate_lead, sign_up, purchase

สรุป: UTM อย่างเดียวไม่พอ - มันตอบได้แค่ว่า traffic มาจากไหน แต่ยังไม่ตอบว่า traffic นั้น convert หรือไม่

1
Banner URL ต้องติด UTM ให้สม่ำเสมอ
2
Landing flow ต้องยิง event สำคัญให้ครบ
3
GA4 ต้อง mark success event เป็น key event

ข้อเสนอ UTM Standard สำหรับทีม

default medium = banner lowercase only underscore only
Parameter ใช้แทนอะไร Format ที่แนะนำ
utm_source ชื่อเว็บไซต์หรือ publisher ที่วาง banner example_news, partner_a
utm_medium channel type banner
utm_campaign initiative ทางธุรกิจ <year><quarter>_<objective>_<theme>
utm_content placement + size + variant <placement>_<size>_<variant>
utm_id internal campaign id cmp_2026q3_014 (optional)

เหตุผลที่เลือก utm_medium=banner: อ่านง่าย, rollout ง่าย, เหมาะกับ manual placements บน external websites

ตัวอย่างที่ควรใช้จริง

Canonical URL pattern

https://www.yourdomain.com/landing-page
?utm_source=<publisher_name>
&utm_medium=banner
&utm_campaign=<year><quarter>_<objective>_<theme>
&utm_content=<placement>_<size>_<variant>

Good examples

  • utm_source=example_news
  • utm_campaign=2026q3_leadgen_crm
  • utm_content=homepage_top_728x90_v1

Avoid these

  • ExampleNews, example-news, exnews
  • summerbannerfinal ที่ไม่สื่อ objective
  • new_final_latest ที่เทียบ creative ไม่ได้

หลักคิดง่ายๆ: source = เว็บที่คนคลิกมา, campaign = เป้าหมายธุรกิจ, content = banner ตัวไหน

เห็น traffic + conversion

สิ่งที่ทีมอยากตอบให้ได้ในที่สุดคือ banner ไหนบนเว็บไหนพา conversion ที่มีคุณภาพมาได้ดีที่สุด ไม่ใช่แค่ใครพา click มาเยอะที่สุด

Event และ Key Event ที่ควรเริ่มเก็บ

Minimum event set

  • page_view
  • click_cta
  • form_start
  • form_submit
  • generate_lead หรือ success page view

ควร mark เป็น key event

  • generate_lead ถ้าเป็น lead gen
  • sign_up ถ้าเป้าหมายคือสมัครใช้งาน
  • purchase ถ้าเป็น ecommerce

ถ้าเรายังไม่มี event success ที่ชัดเจน การ optimize ads จะติดเพดาน เพราะเรารู้เพียงว่า traffic มา - แต่ไม่รู้ว่าธุรกิจได้ผลลัพธ์จริงหรือไม่

Operating Model ที่ทีมควรใช้

1
Marketing เป็นเจ้าของ campaign naming
2
Partnerships / Media เป็นเจ้าของ publisher naming
3
Analytics ตรวจ QA ลิงก์และดูว่า data เข้า GA4 ถูกต้อง
4
Product / Engineering ช่วยให้ event success ถูกยิงอย่างเชื่อถือได้

QA checklist

  • URL เปิดได้จริง
  • UTM ครบและเป็น lowercase
  • Realtime เห็น source / medium / campaign
  • success event ยิงจริง
  • report เทียบ content ได้

หลักสำคัญ: ไม่ให้ใคร generate UTM แบบ free-form โดยไม่มี dictionary กลาง

Definition of done รอบแรก: ทุก banner link ใหม่ต้องออกจาก template กลาง และทีมต้องตอบได้ว่า source ไหน campaign ไหน content ไหนสร้าง lead ได้ดีที่สุด
